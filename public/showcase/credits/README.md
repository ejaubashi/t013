# Credits

Gallery, interface, camera direction, showcase typography, and original procedural sound: Nocturne / Benno's Light project.

Painting reproductions: community CC0 archive `pmilovanov/hermitage-art`, pinned at b8ead49c010eac0c8366bafc4ffaaf1f1a447805. This archive is separate from the State Hermitage Museum's official services.

Artists in the gallery collection: Rembrandt van Rijn, Caravaggio, Henri Matisse, Wassily Kandinsky, Pierre-Auguste Renoir, and Fernand Léger. See `artwork-sources.json` for exact works, original file links, image dimensions, and source hashes.

The media and preview page use Cormorant Garamond and Archivo. The bundled web fonts and their SIL Open Font licenses are in the `fonts/` directory.
